Todo カウントダウン - Windows版 使用方法
========================================

■ 必要な環境
- Windows 10/11
- Node.js (https://nodejs.org/ からダウンロード)

■ ファイル説明

1. start.bat
   - アプリを開く（いつもはこれだけでOK）
   - サーバーが止まっていれば、ウィンドウを出さずにバックグラウンドで起動してからブラウザを開きます
   - すでに起動していれば、ブラウザを開くだけです

2. stop.bat
   - バックグラウンドで動いているサーバーを停止します

3. manage.bat
   - 管理メニュー（状態の確認、再起動、LANモード、自動起動、ログ、バックアップ）

■ 使い方

【毎日の使い方】
- start.bat をダブルクリック

【PCの起動時に自動でサーバーを立ち上げる】
1. manage.bat をダブルクリック
2. [5] Autostart at login: ON を選ぶ
   （やめるときは [6] を選ぶ）

【スマホなど他の端末から使う】
1. manage.bat をダブルクリック
2. [4] Restart with LAN access を選ぶ
3. 表示された「Network」のURLを、スマホのブラウザで開く
   ※ LANモードには認証がありません。同じネットワークの誰でもタスクを閲覧・編集できます。
     自宅など信頼できるネットワークでのみ使ってください。
   ※ 初回はファイアウォールの警告が出ることがあります。「アクセスを許可」してください。

【終了方法】
- stop.bat をダブルクリック

■ データについて
- タスクは data\todos.json に保存されます
- 1日1回、data\backups\ に自動でバックアップされます（直近14日分）
- データが壊れた場合は、stop.bat で停止してから、
  バックアップ（todos-日付.json）を data\todos.json としてコピーしてください

■ トラブルシューティング

Q: 「Port 8080 is used by another program」と表示される
A: 8080番ポートを別のプログラムが使っています。そのプログラムを終了するか、
   コマンドプロンプトで次のように別のポートを指定して起動してください：
     node scripts\launcher.js start --open --port 3000

Q: ブラウザが開かない
A: http://localhost:8080 を手動でブラウザに入力してください

Q: 「Node.js is not installed」と表示される
A: https://nodejs.org/ から Node.js をダウンロードしてインストールしてください

Q: 起動に失敗する
A: manage.bat の [7] でログを確認してください（logs\server.log）
